# X自動投稿（合同誌の宣伝）

SYK出版の合同誌（著者3人）を、1つのXアカウント [@hirosuban](https://x.com/hirosuban) から宣伝するための仕組み。
**本の研究用コードではない**（研究用は`scripts/`）。Google上で動くので、Pythonの環境とは関係しない。

## しくみ

1. 著者がGoogleスプレッドシートの「投稿」シートに1行書く（パート・本文・画像・投稿日時）。
2. 書いた本人が「状態」を「投稿OK」にする。
3. 15分ごとに動くApps Scriptが、投稿日時を過ぎた「投稿OK」の行を1本ずつ@hirosubanから投稿し、
   「投稿済み」と投稿URLを書き戻す。

承認は挟まないので、投稿の前にスクリプトが自動でチェックする。次のどれかに引っかかると投稿せず、
「エラー」にして理由を書き、オーナーにメールする。

- 280を超えている（Xの数え方：日本語は2、URLは23）
- 本文の先頭に【パート名】がない
- `#技術書典`か`#SYK出版`がない、または`#技術書典21`のように番号が付いている
- 画像が5枚以上、開けない、画像ではない、5MBを超えている

ペースの上限もある（「設定」シートで変えられる）。超える分は投稿せず、次の回に回す。

- 1日2本まで
- 前の投稿から3時間以上空ける

「設定」の自動投稿は ON / OFF / テスト の3つ。テストのときは投稿せず、出す予定の内容をメールで知らせる。
**最初はテストになっている。**

## ファイル

| ファイル | どこに貼るか | 中身 |
|---|---|---|
| `common.gs` | 両方 | 文字数の計算（`xlen`）とルールのチェック（`checkPost`）。片方だけ直さないこと |
| `sheet_functions.gs` | シートに紐づくスクリプト | シートの「文字数」「チェック」列の関数`XLEN`・`XCHECK` |
| `autopost.gs` | 独立したスクリプト | シートの準備（`setupSheet`）と自動投稿（`postDue`） |
| `appsscript.json` | 独立したスクリプト | タイムゾーンと権限 |

APIキーを持つのは独立したスクリプトだけ。シートに紐づくスクリプトは、シートの編集者（他の2人）も
開けるので、キーを置かない。

## セットアップ（オーナーがやる）

### A. X側（@hirosubanでログインして）

1. X開発者コンソール（https://console.x.com ）に@hirosubanでサインアップする。利用目的には
   「自分のアカウントで、自分たちの同人誌の告知を予約投稿する」のように書く。
2. アプリを作る。
3. アプリの設定（User authentication settings）で、権限（App permissions）を **Read and Write** にする。
4. 「Keys and tokens」で次の4つを発行してメモする。**権限を変えたあとに発行すること**
   （変える前に発行したAccess Tokenでは投稿できない）。
   - API Key / API Key Secret（Consumer Keys）
   - Access Token / Access Token Secret（@hirosuban用）
5. 料金のページで今の単価を確かめ、クレジットカードを登録してクレジットを買う。
   使いすぎ防止に、使用上限額（spending limit）を設定する。
   参考（非公式情報）：1投稿約$0.015、リンク入りは約$0.20。開催まで数十本なら数ドル程度。

### B. Google側（オーナーのGoogleアカウントで）

6. Googleドライブに共有フォルダ「SYK出版 宣伝」を作り、2人を編集者で共有する（画像置き場）。
7. 新しいスプレッドシートを作る（名前は「SYK出版 投稿」など）。中身は空のままでよい。
   URLの`/d/`と`/edit`の間の文字列がシートID。
8. シートの「拡張機能 → Apps Script」を開き、`common.gs`と`sheet_functions.gs`の2ファイルを作って中身を貼り、保存する。
9. https://script.google.com で「新しいプロジェクト」を作る（シートとは別。名前は「SYK出版 自動投稿」など）。
   - `common.gs`と`autopost.gs`を作って中身を貼る。
   - 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、
     `appsscript.json`の中身を貼る。
   - 「プロジェクトの設定 → スクリプト プロパティ」に次の5つを登録する。

     | プロパティ | 値 |
     |---|---|
     | `SHEET_ID` | 7のシートID |
     | `X_API_KEY` | API Key |
     | `X_API_SECRET` | API Key Secret |
     | `X_ACCESS_TOKEN` | Access Token |
     | `X_ACCESS_TOKEN_SECRET` | Access Token Secret |

10. エディタで`setupSheet`を選んで実行する。Googleの権限確認が出るので許可する。
    シートに「投稿」「ルール」「AIプロンプト」「設定」の4枚ができ、スクリプトが書く列・設定・ルールは
    オーナーだけが編集できるよう保護される。
11. シートを2人と編集者で共有する。
12. 「トリガー」（時計のアイコン）で`postDue`を追加する：時間主導型 → 分ベースのタイマー → 15分おき。

### C. 動作確認（最初はテストのまま）

13. 「投稿」シートに1行書いて「投稿OK」にし、投稿日時を過去にする。エディタで`postDue`を実行する。
    「出す予定の内容」のメールが届き、「エラー・メモ」に`[テスト済み]`と出ればよい（状態は変わらない）。
14. わざとルールに反する行（タグなし、パート名なし、長すぎ）を「投稿OK」で置いて`postDue`を実行し、
    「エラー」と理由が書かれることを確かめる。
15. 最初に出す1本（画像付き）を決めて「設定」の自動投稿をONにし、`postDue`を実行する。
    Xに画像付きで出て、「投稿URL」が書き戻されればよい。続けてもう1本置き、
    3時間空くまで出ないことを確かめる。
16. 2人に「ルール」シートを読んでもらって運用開始。

止めたいときは「設定」の自動投稿をOFFにするだけでよい。

## 運用

- 著者が触るのは、自分の行の パート・本文・画像・投稿日時・書いた人 と、「状態」の 下書き⇔投稿OK だけ。
- 合同誌全体の告知（日付・価格・買える場所）と、時期ごとの固定ポストの差し替えは@hirosubanがやる（固定は手動）。
- 案出しは「AIプロンプト」シートの文面を、各自が普段使っているAIに貼って使う。
- 「投稿済み」の行は書き換えない。Xの投稿は編集できないので、直すなら@hirosubanが消して出し直す。

## つまずいたら

| 症状 | 原因と対処 |
|---|---|
| エラーに`X API 401` | キーかトークンの貼り間違い。権限をRead and Writeにしたあとにトークンを発行し直したか確認 |
| エラーに`X API 403` | アプリの権限が読み取りのみ、またはクレジット切れ |
| エラーに`X API 429` | 送りすぎ。しばらく待つ（状態を「投稿OK」に戻せば次の回に出る） |
| 「画像を開けない」 | 画像を共有フォルダに置いていない、またはリンクがファイルではなくフォルダのもの |
| 「文字数」が`#NAME?` | シートに紐づくスクリプトに`common.gs`と`sheet_functions.gs`を貼っていない |
| 何も投稿されない | 「設定」がOFFかテスト、投稿日時が未来、1日の上限か間隔に引っかかっている、トリガー未設定 |
