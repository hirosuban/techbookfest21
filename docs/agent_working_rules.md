# コーディングエージェントの作業方針

Claude（コーディングエージェント）がこのリポジトリで作業する際の、ユーザーとのやり取りに
関する方針をまとめる。

## 低リスクな作業は確認なしで進める

`logs/YYYY-MM-DD.md`への追記（[docs/research_log_rules.md](research_log_rules.md)参照）のような、
リポジトリ内で完結し、後から簡単に直せる・取り消せる作業については、実行前にユーザーへ
「やりますか？」と確認を取らずにそのまま進めること。

- 対象例: 研究ログへの追記、README等ドキュメントの文言修正、コミットメッセージの下書き など
- 対象外（確認が必要）: 複数の実装方針から選ぶ必要がある設計判断、既存の動いているコードを
  取り消す／書き換える判断、`git push` やファイル削除など取り消しづらい操作

**背景:** 研究ログへの追記について「やりますか？」と確認したところ、ユーザーから
「この手の低リスクな作業は確認なしで進めて」というフィードバックを受けた（2026-09-20）。
確認を挟むこと自体が不要な手間になっていたため、以後は低リスクな作業は都度確認せず
実行し、必要であれば事後に何をしたか報告する運用にする。
