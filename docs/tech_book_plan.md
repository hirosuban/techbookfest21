# 技術書典 出展計画書

## 1. 書籍概要
- **書籍名（仮）:** コードで読み解く愛車デミオの美学：Pythonと画像解析で迫るカーデザインの定量化
- **ターゲット層:**
  - Pythonを用いた画像処理・コンピュータビジョンに興味があるエンジニア
  - 車のメカニズムやデザインが好きで、それをエンジニアリングの視点からアプローチしてみたい人
- **目標ページ数:** 30〜40ページ
- **ゴール:** 
  - デミオのサイドビュー写真から、プロポーション（黄金比・グリッド）を算出・可視化するPythonスクリプトの実装と公開
  - 11月末の技術書典での頒布（デジタル版 / 必要に応じて物理本）

4. **第4章：考察：デミオの黄金比率から見えてきたもの**
   - 実際に算出された数値を基にしたデザインの考察
   - 本手法の限界と今後の展望
