# data/

カーライフ分析本で使うデータを3種類に分けて置く（詳細は [docs/tech_book_plan.md](../docs/tech_book_plan.md) の
「2. データ設計」を参照）。

- **`real/`** — 実際の自分のデミオから収集した給油・維持費データ（本書のストーリーの中心）。
  個人の金額・走行記録を含むため **Git管理対象外**（`.gitignore`参照、`images/`と同じ扱い）。
  まだ手元のログを整理できていないため、現時点では空。
- **`sample/`** — 読者が同じコードを実行できるように用意するサンプルデータ。Git管理対象。
- **`synthetic/`** — 長期間（1年分など）の分析を試すために生成する人工データ。Git管理対象。
  実測値ではないことが分かるよう、ファイル名・カラム等で実データと区別する
  （「データを捏造しない」方針。企画書参照）。
